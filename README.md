# WCF + MVC — Service-Oriented Architecture Demo

Demonstrates integration between **Windows Communication Foundation (WCF)** services and an **ASP.NET MVC** web application.

## Tech Stack

| Component | Technologies |
|-----------|-------------|
| Service Layer | WCF, C#, .NET Framework |
| Web Layer | ASP.NET MVC, Razor Views |
| Communication | SOAP, HTTP Binding |

## Features

- WCF service definition and implementation
- MVC client consuming WCF endpoints
- Service contracts and data contracts
- SOAP-based communication example
